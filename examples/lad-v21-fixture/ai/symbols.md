# Symbol declarations

This inventory covers root tag tables. It does not describe every I/Q/M access in program logic or block-interface variables.

## 默认变量表

| Symbol | Type | Address | Comment status | Comment |
| --- | --- | --- | --- | --- |
| BranchA | Bool | %M0\.0 | present | Parallel branch A marker |
| BranchB | Bool | %M0\.1 | present | Parallel branch B marker |
| ForwardOut | Bool | %Q0\.0 | present | Forward contactor output |
| ReverseOut | Bool | %Q0\.1 | present | Reverse contactor output |
| StartForward | Bool | %I0\.0 | present | Forward start command |
| StartReverse | Bool | %I0\.1 | present | Reverse start command |
