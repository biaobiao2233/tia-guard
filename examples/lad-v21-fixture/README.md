# Owned nonempty V21 LAD fixture

`tia-source/` is the six-file canonical re-export of the self-authored TIA-Guard demo,
copied from the user's supplied test evidence. It contains CPU 1212C
`OrderNumber:6ES7 212-1AE40-0XB0/V4.7`, six Bool tags and three Main/OB1 networks.
No third-party project or `.ap21` binary is included. The original evidence remains untouched.

`ai/` is generated by the current CLI from this canonical source. Regenerate with:

```powershell
tia-guard ai-view examples/lad-v21-fixture/tia-source
```

Networks 1 and 2 are reciprocal output inhibits. Network 3 has two independent branches
sharing the power rail, not an OR join. See [graph contract](../../docs/LAD-GRAPH.md) and
[local verification](../../docs/verification/lad-graph.md). Unit tests copy this fixture to
owned temporary directories before mutating it; the source XML digest is recalculated for
each adversarial test so failures exercise semantic analysis after canonical validation.
