# TIA-Guard v0.1.0-prealpha.1

[中文](#中文) | [English](#english)

## 中文

首个 Windows x64 **pre-alpha 预览版**，包含中文 GUI、CLI、本机 AI Gateway / MCP，以及隔离的 Openness worker。

### 下载

- `tia-guard-v0.1.0-prealpha.1-windows-x64.zip`：普通用户下载此完整包，解压后运行 `TiaGuard.exe`。
- `tia-guard-bridge-v0.1.0-prealpha.1-windows-x64.zip`：只需要独立 Gateway / MCP 时使用。
- `skill.zip`：本机 Agent 的配套调用指引。
- `SHA256SUMS.txt`：以上三个包的 SHA-256 校验值。

Windows / Bridge ZIP 内附中文和英文入门及 Gateway 说明。GUI 当前为中文。包版本为 `0.1.0-prealpha.1`，现有 CLI `--version` 显示核心版本 `0.1.0`。

### 使用前提

Windows x64、.NET Framework 4.8、TIA Portal V21 / Openness、有效的 Siemens TIA Openness 组权限，以及 Git for Windows。Gateway 自带 .NET 8 运行时。发行包不包含 Siemens DLL、TIA 工程二进制或许可证。

### 已验证与范围

本次重新通过 152 个工程契约测试、45 个 Gateway 测试、schema 检查、Windows 构建与 ZIP 内容/CRC 检查；从 ZIP 解压后验证 CLI doctor/version、Gateway HTTP 服务及未授权控制拒绝；GUI 可显示窗口并自动启动 Gateway。校验值见[发行准备记录](../verification/release-prealpha-20261001.md)。

工程支持仍限定为已覆盖的 V21/S7-1200 单 PLC、Main OB1 有限 LAD 与根变量表子集。未知或不支持内容会阻断，不能产生虚假的 PASS。没有在线 PLC 下载、启停、force 或变量写入。

**本次启动与打包检查没有重新验收最新集成版本的完整真实 TIA GUI/Gateway 工程往返及 patch apply。** 历史真实 TIA 记录仅对应各自注明的候选。预览版适合自有离线副本试用，不能视为稳定生产版。

项目将持续更新。使用指南：[中文](../GETTING-STARTED.md) / [English](../GETTING-STARTED.en.md)。

## English

The first Windows x64 **pre-alpha preview** includes the Chinese GUI, CLI, local AI Gateway / MCP and an isolated Openness worker.

### Downloads

- `tia-guard-v0.1.0-prealpha.1-windows-x64.zip`: complete package for ordinary users; extract it and run `TiaGuard.exe`.
- `tia-guard-bridge-v0.1.0-prealpha.1-windows-x64.zip`: standalone Gateway / MCP.
- `skill.zip`: companion instructions for local agents.
- `SHA256SUMS.txt`: SHA-256 checksums for the three packages.

Windows / Bridge ZIPs include Chinese and English getting-started/Gateway guides. The GUI remains Chinese. The package version is `0.1.0-prealpha.1`; the existing CLI reports core version `0.1.0` with `--version`.

### Prerequisites

Windows x64, .NET Framework 4.8, TIA Portal V21 / Openness, effective Siemens TIA Openness group permissions and Git for Windows. The Gateway includes its .NET 8 runtime. No Siemens DLLs, TIA project binaries or licenses are redistributed.

### Verification and scope

This preparation reran 152 engineering contract tests, 45 Gateway tests, schema checks, Windows builds and ZIP content/CRC checks. The extracted ZIP passed CLI doctor/version, Gateway HTTP health/capability checks and rejection of unauthorized controls. The GUI displayed its window and automatically started the Gateway. Checksums are recorded in the [preparation receipt](../verification/release-prealpha-20261001.md).

Engineering coverage remains bounded to the supported V21/S7-1200 single-PLC subset, limited Main OB1 LAD and root tag tables. Unknown or unsupported content blocks instead of producing a false PASS. No online PLC download, start/stop, force or variable writes are exposed.

**These startup/package checks do not requalify the latest integrated real TIA GUI/Gateway engineering round trip or patch apply.** Historical real TIA records apply only to their named candidates. Try the preview on your own offline copies; it is not a stable production release.

Development continues. Getting started: [English](../GETTING-STARTED.en.md) / [中文](../GETTING-STARTED.md).
