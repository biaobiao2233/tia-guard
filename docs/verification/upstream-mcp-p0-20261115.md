保留的失败与修复：

- 初次云端传输测试曾使用错误的 SDK timeoutMs 参数，导致超时测试未按预期结束；停止该轮，改回标准请求 timeout 参数后再执行完整测试。失败轮不计 PASS。
- 重启后首次本机测试（reboot03）失败。原版引擎生成的 TiaMcpServer.startup.log 被过严的文件集合校验拒绝；失败回执的外层断言还掩盖了错误码。修复后只放行版本清单明确列出的这个普通日志，62 个程序文件仍逐项核验；未知文件、链接及代码变化仍拒绝。reboot04 / reboot05 在同一目录通过，未删除日志或重新解压。
