## 目标及边界

为一款准确的 S7-1500 CPU 复用现有 CLI / HTTP / MCP 的 SCL 新建、编译诊断和验证流程。候选为 CPU 1511-1 PN、`OrderNumber:6ES7 511-1AK02-0AB0/V2.9`，不是整个 S7-1500 系列。CPU 型号与固件依据 [Siemens 数据表](https://support.industry.siemens.com/teddatasheet/?caller=SIOS&format=pdf&language=en&mlfbs=6ES7511-1AK02-0AB0)；本机实际目录条目仍待现场读取确认。

CPU allowlist 单独用于 generation，不改旧 RoundTrip/Git/LAD profile 或 PLCSIM 的1212C限制。默认 init 仍生成原有1212C/V4.7输入。任何其他型号、固件或标识别名均拒绝；CPU字段改变会使旧冻结输入/预览失效。

S7-1500必须读取空的软件单元和 Safety 单元，并确认机架仅含准确 CPU；未知、缺失或额外内容不准通过。产品内候选路径额外保存/关闭/从磁盘重开同一自有 staging 工程后再捕获和比较，不把同会话读回当作重开证据。

编译当前目标是 PLC 软件；未自动配置 PLC 密码、用户/角色、访问权限或许可，不把软件编译当作完整硬件编译或运行证明。不连接物理 PLC、不下载、不启动仿真，不修改用户原工程。

## 当前证据状态

候选通过 658 项纯测试：Contracts 152、Bridge.Host 175、Compilation 52、Generation Spec 96 / Engine 82 / Verify 70 / Integration 31。生成 schema 通过 4 个正例与 38 个反例；CLI、Worker、Host、Smoke Release 构建及 Smoke self-test 通过。准确源码哈希及本机结果将在本任务 PR 绑定。纯测试不能证明本机CPU可创建、SCL可编译、回读或运行通过。

实际 stdio MCP 预览已返回准确 S7-1500 CPU/profile 和冻结输入哈希；该检查只预览，不暴露本轮 build 工具、不创建输出、不连接博途，不能替代原生创建/编译验证。
