# 直接使用上游的工作方式

2026-11-15，用户确认以博途软件适配和使用体验为主线。上游已有功能直接使用，不逐项重新包装或复验。既有受限适配器保留为可选流程，不作为所有上游操作的必经入口。

1. 原版 MCP 为主要入口，上游自带 CLI 做批处理/诊断；无需另造 CLI 或 HTTP Gateway。当前客户端也可通过官方 MCP SDK 直接调用原版 stdio 服务，使用相同工具与参数。
2. AI 在独立 TIA 实例和本轮工程副本中完成正常作业，保护用户窗口、原工程及其他运行实例。实际软件 PLC 与真实设备仍须区分，直接用上游不扩大设备和系统权限。
3. 按实际任务读取结构、修改对象、编译、保存；依据软件返回处理错误。工具存在不等于本项目已经实测所有能力，但未实测的现成功能可以正常使用，不先为它建立自有测试工程或适配层。
4. 遇到问题先查上游定义、手册、现成模板和推荐调用顺序；参数问题直接修正调用。真正缺接口、结果不可用或重复操作影响使用时，才记录复现并补最小代码；优先独立兼容或向上游反馈，保持升级方便。
5. 工艺产线保留作小型回归。后续实际工程任务优先已有 PLC 对象修改、HMI 工程与交付体验，不先扩建码垛算法。
